- Thuật toán kiểm tra: phát hiện **vết xước, đốm đen**, đo **chiều dài, chiều cao**

- Tích hợp **Python** để C++ gọi chạy các xử lý bằng Python

- **Tech:** C#, C++, Python, YOLO
